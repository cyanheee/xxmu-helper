# 授权管理（管理员手册）

> 面向：**孤汩（你）**。这份文档只讲怎么发激活码、怎么改设置。

## 一、机制

**激活码 = Base32( HMAC-SHA256(密钥, 学号) ) 取前 16 位**

- 与学号**一一对应**：张三的码只能给张三用，别人拿到也用不了
- App 本地校验，**不联网、不上传任何东西**
- 你不用维护服务器、不用管名单，只需要「谁找你 → 生成一个码发给他」

### 已知局限（如实说明）

| 能防 | 不能防 |
|---|---|
| 随便试码（16 位 Base32 ≈ 80 bit 空间） | 拿到码的人转发给同班同学（如果对方知道对应学号） |
| 张冠李戴（码与学号绑定） | 专业逆向（密钥打包在 APK 里，理论上能被提取） |

要真正做到「能远程踢人 / 能看谁在用」，必须改成联机校验 + 服务器。
当前方案的价值是：**零成本、零隐私风险（我不接触任何人密码和课表）**。

## 二、生成激活码

```powershell
cd "D:\dsh\DSH Desktop\xxmu-app"

# 单个
python tools\gen_license.py 20261440105

# 批量
python tools\gen_license.py 20261440105 20261440106 20261440107

# 从文件读（每行一个学号，# 开头是注释）
python tools\gen_license.py --file ids.txt

# 导出 CSV（可以直接发给班委）
python tools\gen_license.py --file ids.txt -o licenses.csv
```

输出示例：

```
学号           激活码
--------------------------------
20261440105  24DN-JFSG-7NKV-RNBT
20261440106  636R-9999-GRDM-5TR4
```

**把这个码发给对方即可**，对方在 App 激活页填「学号 + 激活码」。

### 自检（改过代码后必跑）

```powershell
python tools\gen_license.py --selftest
```

必须输出「自检结果: 通过」。如果失败，说明 `gen_license.py` 的 `SECRET`
和 `web/license.js` 的 `SECRET` 不一致了——那样生成的码在 App 里全部无效。

## 三、把自己设成管理员（免激活码）

编辑 `web/license.js`，找到：

```js
const ADMIN_IDS = [
  // '20261440105',
];
```

改成你自己的学号：

```js
const ADMIN_IDS = [
  '20261440105',    // ← 换成你的真实学号
];
```

这样你输入学号、激活码留空也能进。改完要重新打包（见第五节）。

## 四、换密钥（会让所有已发码失效）

编辑 `web/license.js`：

```js
const SECRET = 'XXMU-HELPER-GU-2026-v1';
```

同时改 `tools/gen_license.py` 的同名常量，**两处必须一模一样**。
改完跑 `--selftest` 确认，然后重新打包。

> 什么时候该换：怀疑密钥泄露、或者想把之前发出去的码全部作废。

## 五、重新打包

```powershell
cd "D:\dsh\DSH Desktop\xxmu-app"
python tools\build_apk.py
```

产物：`apk/xxmu-helper-v0.4.0.apk`

**注意**：如果改了 `AndroidManifest.xml` 里的 `versionName`，脚本会自动用新版本号命名产物。

## 七、常见问题

**Q：学生说码输进去提示「激活码不正确」**
A：九成是学号填错了。码是和学号绑定的，让他核对学号。
    另外码里没有字母 `I / L / O / U`（用的是 Crockford Base32，已刻意避开），
    如果看到这几个字母，说明他抄错了。

**Q：学生换手机了怎么办？**
A：直接用同一个码重新激活，不用重新生成。

**Q：想临时让某些人不能用？**
A：本地方案做不到远程失效，只能让他卸载。这个限制在选方案时已确认接受。
    如果以后真需要，得改联机校验。

**Q：激活码能重复用吗？**
A：可以。同一个学号在任何设备上激活都有效（码是算出来的，不是一次性令牌）。
