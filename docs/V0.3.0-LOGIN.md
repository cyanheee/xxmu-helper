# v0.3.0 — App 内登录（全校可用）

> 这一版把「PC 抓数据 → 推 JSON 给手机」升级为「App 内登录 → 自动拉数据」。
> 全校同学装上就能用自己的学号登录，不再需要电脑和 root。

## 一、用户怎么用

1. 装 `apk/xxmu-helper-v0.3.0.apk`
2. 「我的」→ **登录教务（学校官方页面）**
3. 在弹出的学校官方登录页里输入学号 + 密码 + 验证码（**就是平时网页登录那个页面**）
4. 登录成功后自动回到 App，首次会问一次学号（只存本机）
5. 自动同步课表，课表页立刻显示

之后每次打开 App 会自动同步一次（静默，失败不打扰）。登录过期时，同步会提示重新登录。

## 二、为什么用内嵌官方登录页，而不是自己画登录框

| 方案 | 问题 |
|---|---|
| 自绘登录框 | 青果的密码要跑自定义 DES + 时间戳 + 临时 deskey，**学校随时能改**；一改就得发新版 App，且旧版直接废掉 |
| **内嵌官方页** | 用户看到什么就操作什么。学校改版、加滑块、加短信验证码，**App 一行不用改** |

代价是同步时拿不到明文密码（这是好事），只能拿到登录后的 Cookie。

## 三、技术实现

### 数据流

```
用户点登录
  → Host.openLogin()                     [Java] 弹 Dialog 装 WebView
  → WebView 打开 https://qgjw.xxmu.edu.cn/ （学校官方页）
  → 用户在官方页正常登录
  → onPageFinished 检测到已离开 /cas/ 且进入 /frame/ 或 /student/
  → CookieManager.flush()
  → 回调 window.__onLoginDone(true)      [JS]
  → 首次问学号 → Host.setPref('xxmu_user', x)
  → syncSchedule()
      → XXMU.fetchScheduleHtml(user, term)
          → Host.fetchScheduleHtml(b64("xn=2026&xq=0&xh=学号"))
              → Http.request(带 Cookie + 教务 Referer)
          → 返回 "<code>|ISO-8859-1原始字节"
          → decodeAuto() 嗅探 UTF-8 / GBK
      → XXMU.parseKb(html)     → cells
      → XXMU.normalize(cells)  → courses[]
      → Host.saveCachedSchedule(json)
  → load() 重新渲染
```

### 文件改动

| 文件 | 说明 |
|---|---|
| `web/sync.js` | **新增**。纯 JS 的抓取 + 解析层：`parseWeeks` / `parseKb` / `normalize` / `buildSchedule` / `guessTerm` |
| `android/src/com/xxmu/helper/Http.java` | **新增**。极简 HTTP（HttpURLConnection，零依赖），支持 Cookie / Referer / gzip，返回 `<code>\|<bytes>` |
| `android/.../MainActivity.java` | 重写。登录 WebView、Cookie 导出、缓存读写、Prefs、HTTP 桥 |
| `web/app.js` | 数据优先级改为 **外部JSON → App缓存 → 内置**；新增登录/同步/退出按钮逻辑 |
| `web/index.html` | 「我的」页加登录卡片；引入 `sync.js` |
| `tools/build_apk.py` | **新增**。Windows 一键构建（替代 Termux 的 build_apk.sh） |

### 关键约定（不要改坏）

1. **青果课表接口必须带 Referer** `https://qgjw.xxmu.edu.cn/student/xkjg.wdkb.jsp?menucode=S20301`，否则返回登录页。
2. **Cookie 必须持久化**：`onPause` 里 `CookieManager.flush()`，否则重启掉登录态。
3. **编码不能写死**：青果课表正文是 GBK，但「凭证已失效」提示是 UTF-8。`decodeAuto()` 先试 UTF-8(fatal) 再退 GBK。
4. **Java 返回 ISO-8859-1 保留原始字节**，不要在 Java 侧解码，否则 GBK 会丢信息。
5. **数据优先级**：外部 JSON（PC 同步）> App 缓存 > 内置。三者都要保留，方便调试。
6. **学期参数自动推断**：`guessTerm()` 按当前月份推 `xn`/`xq`（8月~次年1月=秋 xq=0；2~7月=春 xq=1）。跨学期不会失效。

## 四、构建

```powershell
cd "D:\dsh\DSH Desktop\xxmu-app"
python tools\build_apk.py            # 完整构建
python tools\build_apk.py --install  # 构建并 adb 安装
```

依赖（本机已就绪）：
- JDK 17 `C:\Program Files\Eclipse Adoptium\jdk-17...`
- Android SDK `D:\android-sdk`（platforms/android-33 + build-tools/33.0.2）
- keystore `android/xxmu.jks`（pass `xxmu123`，**首次已生成，务必备份**）

**坑**：`d8.bat` / `apksigner.bat` 在 JDK17 下会因 `-Djava.ext.dirs` 报
`Could not create the Java Virtual Machine`。`build_apk.py` 已改为直接
`java -cp d8.jar` / `java -jar apksigner.jar`。

## 六、当前边界

- **学习通作业**仍然走 PC 侧 `core/sync_hw.py`（cookie 库方式）。App 内 WebView
  登录学习通是下一步，因为超星页面更复杂、更容易触发风控。
- **喜鹊儿接口**未接入。已逆出加密算法（`core/kingosoft.py`）但被服务端
  「请升级到最新版本」版本门挡住，需真机抓包取真实 `appinfo`。
- **没有服务器**，所有数据只在用户手机本地。好处：密码不出手机、零运维成本；
  代价：无法做后台推送、无法做班级共享课表。
