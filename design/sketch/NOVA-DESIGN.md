# NOVA ·「万象舱」全新主题设计说明

> 定位：**不是给旧版换皮，是保留功能、重新开发一款全新软件**。
> v1.1.48/1.1.50/1.1.54 的西部涂鸦骨架（纸卡片流 / 针脚 / 暖棕描边 / 旧 Tab / 旧色板）**整体作废**。
> 原型文件：`nova-preview.html` + `nova-preview.css`（只在 `design/sketch/` 下，正式 `web/` 一行未动）。
> 双轴正交：`data-skin="nova"`（是否启用新主题）× `data-theme="light|dark"`（介质明度），互不干扰。

## 1. 保留的功能清单（唯一真源，不许加减）

1. 课表：21 周切换、上下课时间、深色模式
2. 学习通作业与考试：完成情况 + 截止时间
3. 饮水机：扫一次二维码绑定设备，之后免验证接热水（**只做不涉资金的动作**）
4. 校园 WIKI：校历 / 招生办 / 附属医院 / 校训（数据来自官网）
5. 校园图片 + 留言板（图片需管理员审核）

明令禁止出现：洗衣机、报修、停车场、宿舍空调、电费度数、kWh、缴费代办理。

## 4. 三个招牌交互（YG 点名的两个 + 我加的一个）

1. **动态传送带切周**：横向拖动 21 格皮带，松手吸附最近周；吸附瞬间主舷窗课表做 220ms 横向滑入 + 一次像素硬闪，周数段码滚动。滚轮与皮带持续 12s 缓移（可见机械运动）。
2. **磁带门时空穿越**：点磁带框 → 以触点为 `transform-origin`，`scale()` 放大到铺满视口；放大途中背景色相偏移 + 扫描线加速 + 计数器滚动，卷轴开转；进入后 A 面是作业清单（名称 / 截止 / 完成情况），点「翻面 B」看考试；✕ 缩回原位。
3. **波段拨盘切频道**：五个频道做成收音机调频刻度，当前频道一颗发光指示珠滑过去（赛博段码），主区按频道做 stagger 换组，不是普通 Tab 高亮。

 universality：三个交互都只用 `transform / opacity / background-position`，零重排；`prefers-reduced-motion` 一键全停。

## 5. 深浅正交

| | light「天光舱」 | dark「夜航舱」 |
|---|---|---|
| 舱体 | 冷瓷白 `#E8EEF0` + 水彩晕染 | 夜航蓝 `#121A2E` + 冷晕染 |
| 舷窗玻璃 | 深青 `#122A38` | 更深 `#0A1826`，发光提一档 |
| 霓虹 | 收敛，只做点缀 | 提亮，做主指示 |
| 风格配额 | **完全相同** | **完全相同** |

切 `data-theme` 只换介质明度与发光强度，不动任何器官的形状、位置、配比。

## 8. 落地路径（点头之后才做）

1. `web/skin-nova.css` 覆盖层 + `web/skin.js`（localStorage 记住 skin，和 theme.js 并行互不覆盖）
2. 设置页加「外观：经典 / 万象舱」两档开关（独立于深浅两档）
3. **不动 app.js 的 4700 行 DOM id 绑定**：用 CSS 重绘顶栏/底栏、给既有 section 套器官装饰层；传送带 / 磁带门 / 波段拨盘做成独立浮层组件，通过桥接调用原有切周与切 Tab 函数
