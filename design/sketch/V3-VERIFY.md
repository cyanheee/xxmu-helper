## 总判决

**一句话：台面层（材质轴）真的立起来了，器官层（注意力轴）分工也守住了 §3.5.3 的每一条消解规则；但两层之间有个洞——遮罩/深色档这两处「通用基础设施」还是 v1 的旧配方，把好不容易做出来的材质成片压死。修完 2 条 P0 + 4 条 P1（遮罩、深色档材质、课卡灰度与圆角、底栏定位）就能交付，其余可留到下一轮。**

**分数：6.5 / 10**（对比 SIGNATURE-CRITIC 上一轮 4.5/10；扣分项集中在「遮罩」与「深色档材质塌平」两处系统问题，而不是百花齐放本身）

| 轴 | 判定 | 一句话 |
|---|---|---|
| 材质轴（纸/皮革/黄铜/玻璃/树脂/相纸/电路） | **成立** | 浅色档 7 种材质肉眼可辨，米黄纸、棕皮革、黄铜缝线、黑屏掌机都在 |
| 注意力轴（A 主角 / B 配角 / C 材质 / D 降噪） | **成立** | 一屏只有一个器官抢话筒，比 v2 的「七器官抢话筒」是质变 |
| 冲突消解（§3.5.3 五条判例） | **0 违规** | 五类判例逐条实测，全部 0 |
| 灰度（可读性底盘） | **不达标** | 课卡 vs 空格子 10.05/255（门槛 20） |
| 深色档 | **半塌** | 紫夜舱成立，但米黄纸、票纸色相在深色档全部丢失，只剩明度 |

## ② 灰度实测（门槛：四级单调 + 课卡 vs 空格子 ≥ 20）

### 2.1 课表四级（`v3-kb-light.png`，98679 B）

| 级 | 取样区 (x,y,w,h) | meanY | 中心色 |
|---|---|---|---|
| 课卡（纯白区） | (95,515,70,20) | **240.40** | `#FFFFFF` |
| 课卡（纯像素） | (150,470,20,20) | **249.87** | `#FFFFFF` |
| 课卡（含文字） | (130,640,40,40) | 227.29 | `#011438`（标题墨色） |
| 页底 | (200,1230,60,20) | **243.13** | `#F0F3F5` |
| 网格槽底 | (250,455,20,10) | **231.80** | `#E2E9ED` |
| 空格子 | (290,640,60,40) | **230.35** | `#E2E9ED` |
| 列头 | — | 225.95 | `#CDD3D8` |

**判定：✗ 不达标（差 10.05 / 19.52，门槛 20）**

- 取纯白像素：课卡 249.87 → 页底 243.13 → 槽底 231.80 → 空格子 230.35，**单调成立**，但 **课卡−空格子 = 19.52 < 20**（差 0.48 分）。
- 取整卡均值：课卡 240.40 **低于**页底 243.13，**单调破裂**（卡片看起来比页底还「沉」）。
- 根因：`web/nova-medium.css:205-213` 的注释自称「空格子 #E2E9ED（Y≈231.4）与课卡 254 拉开 22.4」—— 那个 22.4 是把课卡当成纯 254 算的；课卡有 4px 内边距 + 1px 描边 + 标题墨字，整卡均值只有 240.40，**实际只差 10.05**。注释口径要改，或者把空格子压到 `#DCE4E8`（Y≈225）才真能拉开 20。
- 另外空格子与槽底差 **1.45**（231.80 vs 230.35）—— 这两级在实拍里几乎不可分，四级实际只有三级。

| 图 | 材质 | meanY | 中心色 | 与页底差 |

## 优点清单（这版真正做对的事）

1. **四角彩色光斑彻底消失。**v1/v2 那五团 radial-gradient 已清除，`v3-kb-light` 底色是干净的冷瓷，四角无晕染 —— 这是三轮里最大的一次进步。

4. **像素舱做到了「破例但不越位」。**0 圆角 + 点阵抖动 + 1px 硬边 + 3px 硬投影全在机身内，周边卡片仍是 8/12px 圆角。`web/nova-pixel.css` 8 处 `border-radius:0` 逐条核对，无一处溢出。
5. **§3.5.3 五条判例 0 违规。**这是本轮最硬的一条：切角只给 dial、苔藓绿不出 plate、像素 0 圆角不外溢、皮革与票纸不同屏、砖红与珊瑚不同框 —— 全部实测通过。
6. **珊瑚回到「只给威胁」。**全站 coralHi 只有 pop-light 16px（危险按钮抗锯齿）+ 2px（logo 边缘）+ rain-light 5px（橙标签误判）。「确定清空」从 v1 的珊瑚粉改成砖红 `#C0304E` + 白字 5.56:1，语义更准确。

9. **11 个器官里 9 个可辨识**（belt/tape/dial/clipping/ticket/swipe/plate/pixel/rain/polaroid），对比上一轮「七个器官同时抢话筒」是质变。
10. **WIKI 页是全站标杆。**纸卡 + 撕角 + 折角 + 墨描边，3 种材质、四级灰度、无抢戏色 —— 建议其他页照着它调。
