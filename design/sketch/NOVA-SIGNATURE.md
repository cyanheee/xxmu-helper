# NOVA 现象级设计纲领（v3 · 双轴版）

> YG 的两句话必须同时成立：
> - 「我要的是一个现象级，让人眼前一亮，又不会太过浮夸容易腻的产品。」（m05926）
> - 「不要一家独大，多种艺术风格并存，百花齐放。」（m09731，**方向修正**）
>
> 前半句要 **signature（记忆点）**，后半句要 **低熵（长期不疲劳）**。这两件事不是靠加东西同时满足的，是靠**排优先级**。
> 本文件是配色/器官/动效所有改动的宪法。与它冲突的实现一律以它为准。

## 0.0 v3 方向修正（写在最前面，因为它推翻 v2 的一条执行）

v2 把「融合得不好看」理解成了「把三种介质统一成冷瓷」，于是执行了一轮**减法**：
米黄纸全退役、深蓝玻璃降级、涂鸦降成一根灰线、作业标签五色相压成两档。
**结果是把「融合」做成了「一家独大」。**

YG 的纠正：「不要一家独大，多种艺术风格并存，百花齐放。」

### 真正的病根（v2 诊断漏掉的）

> **「融合得不好看」≠「风格太多」，而是「风格之间没有共同的物理规则」。**

举例：西部涂鸦的硬边手绘风、蒸汽朋克的黄铜齿轮、像素风的 8bit 方块、GBA 的掌机按键、
赛博 HUD 的切角框——这五个风格**互不冲突**，它们各自都有极强的识别度。
把它们拼在一起会「乱」，是因为它们**各自用了一套自己的光、自己的边、自己的圆角、自己的尺度**：
西部用 4px 不等圆角 + 2px 硬影，蒸汽朋克用金属渐变 + 铜绿，赛博用切角 + 霓虹发光，
像素用 0 圆角 + 2px 硬投影。**五套物理规则并置 = 视觉噪声。**

### v3 的解法：双轴（这是本文件的全部改动）

```
        注意力轴（纵向）：谁抢眼
        ┌────────────────────────────────┐
   高   │  A 主角   belt / tape          │  ← 可以高饱和、可以动、可以第一眼
        │  B 配角   dial / plate         │  ← 1 处强调色
        │  C 材质   clipping/ticket/      │
        │            polaroid             │  ← 只做介质差异
        │  D 彩蛋   pixel/rain/doodle/    │
        │            swipe                │  ← 安静但有性格
   低   └────────────────────────────────┘

        材质轴（横向）：每件器官用什么材料做
        ┌────────────────────────────────┐
        │  纸 / 皮革 / 黄铜 / 玻璃 /      │
        │  树脂 / 陶瓷 / 相纸 / 电路      │
        │  ——每种材料只归一到「同一盏灯」  │
        │  ——不归一到「同一种材料」        │
        └────────────────────────────────┘
```

**铁律（两条，同时成立，缺一不可）**：

1. **材质轴：允许多种材料并存，但所有材料共用同一套「物理规则」。**
   - 所有阴影**只向下**（`box-shadow` 的 y 必须为正，不许向上投影）。
   - 所有高光**只在上边缘**（`inset 0 1px 0 rgba(255,255,255,α)`）。
   - 所有材料**共用同一组尺度**（圆角两档：控件 8px / 容器 12px；内边距 ≥12px；4px 基准网格）。
   - 所有材料**共用同一组文字层级**（字号 11/13/15/18/24；字重 400/500/700）。
   → 这套物理规则就是《The Last Night》的答案：3D 箱子 + 2D 纸片人 + 预渲飞车混在一起不违和，
   因为**光全从上往下**。我们统一的是**光**，不是材质。

2. **注意力轴：同一屏里，饱和色只允许出现在一处。**
   - 「一处」指的是**一件器官的一个局部**，不是全站一种颜色。
   - 器官**外壳**可以有自己的材质色（黄铜齿轮、皮革压边、相纸白、砖红卡面），
     因为材质色是**低饱和**的、面积小、形状稳定。
   - 器官**内容区**必须回到中性阶 + 主色，否则材质会变成第二个强调色。
   - 信号色（珊瑚）仍然只给威胁语义：待交 / 待考 / 逾期 / 删除 / 危险确认。

### 因此，以下 v2 结论**部分作废**

| v2 结论 | v3 判定 |
|---|---|
| §0 器官分级 A2/B2/C3/D4 | **保留**。分级管的是「注意力」，不是「材质」。D 级器官照样可以有鲜明材质（像素舱就是 8bit 机）。 |
| §1.1 三级可读性（高饱和只给第 3 级） | **保留但重定义**。第 3 级 = 威胁语义 + 「A 级器官的那一处」。材质色（黄铜/砖红/相纸白）属第 1.5 级：**低饱和、小面积、稳定形状**，不算强调色。 |
| §1.4 同一套光的逻辑 | **升格为第一铁律**。这是「融合」的技术答案。 |
| §2.1 配色配额（主色 1 + 信号色 1） | **保留**，但补充「材质色配额」：材质色不计入主色配额，因为它不用于普通 UI（按钮/标签/普通卡片），只做器官外壳与内容载体。**v2 把米黄纸全退役是执行错误** —— 纸是 C 级器官的合法材质，不是「第四种介质」。 |
| §2.4 浅色档 = 「冷白瓷的仪表盘」 | **修正**为「冷白瓷的**台面**上摆着各种器物」：底与普通卡片是冷瓷，但纸上要有纸、黄铜要有黄铜、相纸要有相纸。 |
| §0「11 个器官 = 0 个 signature」 | **保留为问题**，但解法不是收敛成 1 个主角。解法是：**让每件器官在「材质上」独一无二，在「注意力上」有明确排序**。百花齐放 ≠ 乱成一锅。 |

### v3 的验收标准（替代 v2 的「42 簇 → 1 簇」）

- ❌ 不再以「高饱和簇总数」为指标（它会把材质色也当罪魁）。
- ✅ 改为三条可测的：
  1. **同屏同色相冲突数 = 0**：一页里不允许有两个不相干的强色相并存。
  2. **灰度后层级仍分得清**（材料可以没颜色，但结构不能塌）。
  3. **每件器官能被一眼认出是「什么材料」**（纸就是纸，黄铜就是黄铜）——这是「百花齐放」的验收。

## 0. 核心判决（原 v2 §0，保留并补充材质轴）

现在的 NOVA 有三个真实问题，全部同源：

| 现象 | 病根 |
|---|---|
| 「融合得不太好看」 | 11 个器官各自是完整风格，同一屏出现 3~4 种介质（冷瓷白卡 / 米黄纸 / 深蓝玻璃），像三个 App 拼在一起 |
| 「浮夸」 | 每个器官都在抢注意力，没有主次 → 眼睛无处落 |
| 「容易腻」 | 高饱和 + 高频动效 + 处处有梗，第一眼信息过载，第三眼开始吵 |

**结论：现象级不是「每个地方都很酷」，是「一个地方酷到记住，其他地方安静到不打扰」。**
一杯咖啡店的记忆点是那台机器，不是墙上每块砖都有花纹。

### 器官分级（硬性）

| 级别 | 器官 | 配额 | 视觉权力 |
|---|---|---|---|
| **A · 主角** | 周次传送带 `belt`、磁带门 `tape` | 2 | 可以有高饱和、可以有动效、可以抢第一眼 |
| **B · 配角** | 波段拨盘 `dial`、设备铭牌 `plate` | 2 | 只允许 1 处强调色，静态或 ≤1 个 3s 缓动 |
| **C · 材质** | 剪报 `clipping`、票券 `ticket`、拍立得 `polaroid` | 3 | 只做**介质差异**（纸/票/照片的质感），不额外加色、不加动效 |
| **D · 降噪** | 像素舱 `pixel`、截止矩阵 `rain`、涂鸦 `doodle`、刷票 `swipe` | 4 | **不许新增颜色**，只允许用现有中性色 + 主色单色；动效只保留「状态变化」那一下 |

D 级器官不是删掉——它们是「彩蛋」，用户用一周才会发现。**彩蛋的价值在于「发现」，不在于「看见」。**

## 1. 从商业像素地牢肉鸽抄什么（已考证，非臆测）

### 1.1 《死亡细胞》——三级可读性分层（最重要的一条）
美术总监 Gwenael Masse 的原话逻辑（gamelook 2018-08 访谈 + gameres 工作流分析）：

> 饱和色彩的背景可以让角色非常醒目……让玩家很快发现屏幕上出现了新元素。

他们不是「配得好看」，是按**注意力优先级**分配饱和度，三级：

| 层级 | 死亡细胞的做法 | NOVA 的映射 |
|---|---|---|
| 第 1 级 · 背景 | 饱和度**互相融合**、不许有明显不和谐 | 介质层（底色 / 卡片 / 器官外壳）——**必须几乎无色**，只有明度差 |
| 第 2 级 · 玩法元素 | 与背景**有对比**，但不刺眼 | 内容（课名、作业名、读数）——中性深色，靠字重和字号立起来 |
| 第 3 级 · 威胁 | **最高饱和 + 最强对比**，全屏只给它 | 「待交 / 待考 / 即将截止」+ 唯一的强调色 |

**硬规则：全站高饱和色只允许出现在第 3 级。** 现在粉红用在每张卡标题前的 ▮ 方块、表单标签红点——那是把「威胁色」当装饰用，直接把三级塌成一级。**这一条必须改掉。**

### 1.2 灰度稿 → 换调色板（重做成本极低）
> 「首先，在使用地图之前，我们就用灰色调画出了背景视差的纹理，所以接下来调整地图的时候要做的就是为一个生物改变调色板。」

他们的关卡**结构是灰阶定死的，配色只是叠上去的一层 tint**。

**NOVA 落法**：所有容器/卡片/器官外壳的层次关系必须**只用明度**表达得通（把屏幕调成灰度截图，层级依然分得清）。颜色只是最后一层薄 tint。
→ 这条是「不容易腻」的技术保障：换季、换主题、换配色不动结构。

### 1.3 室内/户外两种调色板策略
- 室内关卡 = **补充调色板**（complementary，对比强）
- 户外关卡 = **同类色调色板**（analogous，微妙 + 景深）

**NOVA 落法**：一屏之内只用同类色（analogous）。要「跳」的地方靠**明度**跳，不靠换色相跳。
跨页之间允许换色系（课表偏冷、WIKI 偏暖），但**页内不许出现第三个色相**。

### 1.4 The Last Night——统一感的来源是「同一套光的逻辑」
> 每个角色的 sprite 都有一个顶光图层，通过调节这个顶光图层的亮度来模拟出受路灯和闪电的影响。

3D 箱子 + 2D 纸片人 + 预渲飞车，三种技术混在一起却不违和——因为**光全部从上往下**。

**NOVA 落法（铁律）**：
- 所有阴影**只向下**，`box-shadow` 的 y 必须为正、不许出现向上投影。
- 所有高光**只在上边缘**，`inset 0 1px 0 rgba(255,255,255,α)`。
- 器官的「壳」与「内容」共用同一个光源方向，不许一个亮一个暗。
→ 这条是「融合」的技术答案。不是把风格调成一样，是让它们**被同一盏灯照着**。

### 1.5 像素风的硬规则（只对 `pixel` 这一个器官生效）
- 像素风**禁用** `border-radius`、渐变、柔和阴影 → 要用**硬边 + 硬投影（`box-shadow: Npx Npx 0 硬色`）+ 抖动（dithering）过渡**。
- 参考对比度实测：`#1a1c2c` on `#f4f4f4` = 15.32:1；次要 `#5f574f` = 6.44:1；muted `#8b8680` = 3.28:1（AAA 不合格）。
- 「1x 放大下认不出是什么，这个 sprite 就失败了」→ 像素舱在小屏上必须一眼看懂是「掌机」，不能靠细节。
- 「更少的帧数往往更好」→ 像素舱的动效最多 2 帧（开/关）。

**约束**：像素只占 1 个器官。全站像素化 = 浮夸 + 腻。

## 2. 配色：一个主色，一个信号色，其余全是灰阶

### 2.1 配额（硬上限）

**v3 补充：材质色是独立配额，不占主色名额。** 理由：材质色只出现在器官外壳与内容载体上，
面积小、形状稳定、低饱和，它不与主色争「注意力」——就像一台黄铜收音机的铜，
不会跟旁边塑料遥控器的蓝按钮打架。

| 角色 | 数量 | 允许用在哪 |
|---|---|---|
| 主色（青绿系） | 1 | 主按钮、选中态、A 级器官唯一强调、进度/已完成的正面语义 |
| 信号色（珊瑚/红） | 1 | **只**给「待交 / 待考 / 逾期 / 删除 / 危险确认」 |
| 中性阶 | 7~9 档 | 其余一切：底色、卡片、描边、正文、次要文字、禁用 |
| 材质色（黄铜 `brass`、金币 `coin`、纸 `tape`、皮革 `leather`、相纸 `photo`） | **保留并扩编** | **只作为 A/C 级器官的「材质」**，不许外溢到普通 UI（按钮/标签/卡片）。材质色必须低饱和（与信号色拉开距离）、小面积、形状稳定。 |

现在浅色档有 7 个强调色（青/珊瑚/紫/草绿/橙/黄铜/金币）在跑 = 灾难。紫色从普通 UI 里撤掉，只留深色档。
**v2 曾把米黄纸（`--n-tape`）整个退役 —— 这是执行错误**：纸是 C 级器官（剪报、磁带门、票券）的合法材质，
不是「第四种介质」。正确做法是**把它降饱和 + 统一光照**，而不是删掉。

### 2.2 用 HSB 加减法生成整套色阶（不要手选 7 个色值）
同一个色相 H，其余靠 S/B 反比调整：

- **变暗** = 饱和度 **↑**、亮度 **↓**（例：S24/B96 → S40/B82）
- **变亮** = 饱和度 **↓**、亮度 **↑**
- 要偏冷 → 色相往 RGB 方向挪；要偏暖 → 往 CMY 方向挪

三级文字色**不要选三个色值**，用同一个深色的三个不透明度（0.90 / 0.62 / 0.40）——更稳，且换主题时不会崩。

### 2.3 对比度底线（WCAG，可实测）
- 正文 ≥ **4.5:1**
- 大字（≥18.66px 或 ≥14px 加粗）≥ **3:1**
- 次要/说明文字 ≥ **4.5:1**（现在的 muted `#7B8B99` on 冷白底约 3.4:1，**不合格**，要压深）
- 深色档**不许用纯黑 `#000000`** 做背景或表面（已用 `#1A1430`，正确）

### 2.4 浅色档的目标观感（v3 修正）

> **冷白瓷的台面，摆着各种器物。**
> 底与普通卡片是冷白瓷；但纸上要有纸的暖黄与纤维感，黄铜要有黄铜的金属暗面，
> 相纸要有相纸的冷白与厚度，皮革要有皮革的哑光与压边。
> 台面统一，器物各异 —— 这是「百花齐放」而不乱的做法。

反面（现状）：「水彩纸 + 唱片封套 + 电路板拼在一起」。
**注意**：反面里的「唱片封套」和「电路板」指的是**材料没有共同物理规则**，
不是「材料本身太多」。八种材料各守各的规矩才是问题。

## 3. 动效：只传达信息，其余全砍

- 时长：**150–300ms** 用于交互反馈；状态变化 ≤ 400ms。
- 缓动：全站统一两条曲线（`cubic-bezier(.2,.7,.3,1)` 进 / `cubic-bezier(.4,0,.2,1)` 出），不许每个器官自定义。
- **循环动效只允许 2 处**（A 级器官各 1 处，周期 ≥6s、幅度极小）。现在 2/5/6/7/8/9/11/12/18s 九条周期同时在跑 = 视觉噪音。
- 装饰性动效（漂浮、呼吸、飞石、余光扫过）**全部降为静态**，或只在 hover/聚焦时触发一次。
- `prefers-reduced-motion` 总闸必须覆盖全部新增动效。
- 判据：「这个动效如果删掉，用户会丢失信息吗？」答否 → 删。

## 3.5 风格谱系（v3 新增 · 「有机结合」的施工图）

YG 的原话（m09746）：
> 「像素，gba，赛博朋克，宝可梦风等等，还有宫崎骏风格，赛博风，动漫风，漫画风这些都可以，还有涂鸦风。让他们有机的结合起来。」

**「有机结合」的操作定义**（本节是全队施工图）：
> 每种风格**认领一件器官的「材质 + 交互」**，风格之间**通过共用的物理规则互相咬合**，
> 而不是把风格贴纸糊在同一块屏幕上。

### 3.5.1 风格 → 器官 → 材质 认领表（配额制：一_style 一_器官，不许超发）

| 风格 | 认领器官 | 材质 | 交互特征 | 注意力级 |
|---|---|---|---|---|
| **GBA / 像素掌机** | `pixel` 像素舱 | 8bit 塑料壳 + 点阵屏 | 十字键/AB 键、硬边、按键位移 | D（彩蛋） |

**表格读法**：一屏里通常只出现 3~4 种材质（不同页不同），但它们**全部遵守 §0.0 的物理规则**，
所以「多种风格并存」看起来是**丰富**而不是**乱**。

### 3.5.2 「有机」的三个咬合点（这三条是「有机结合」的真正含义）

1. **材料之间有接触关系**（不是并排，是搭在一起）：
   - 磁带门是**黄铜轴**（蒸汽朋克）插在**冷墨树脂舱体**（赛博）里，轴心有一点**暖光**（宫崎骏）。
   - 传送带的**皮革压边**（西部）包着**黄铜齿轮**（蒸汽朋克），齿轮上有一道**扫描高光**（赛博）。
   - 剪报的**报纸纸**（漫画）压在**拍立得相纸**（摄影）上，纸边有**蜡笔手绘**（宝可梦）。
   → 咬合点 = **一盏灯照到两种材料上，两种材料都接住同一条高光与同一条阴影**。

2. **风格之间借对方的语言**（避免每件器官孤立成一个 Demo）：
   - `pixel` 的点阵屏里，画的是 `belt` 的周次数字 → 像素风给传送带提供「8bit HUD」。
   - `rain` 的赛博矩阵里，读的是 `tape` 的作业数 → 赛博风给磁带门提供「数据面板」。
   - `doodle` 的涂鸦给 `clipping` 的剪报加手绘批注 → 涂鸦风给漫画风加「活气」。
   - `swipe` 的校园卡上，印着 `plate` 的设备编号 → 涂鸦/写实风给铭牌舱提供「实物」。
   → 每件器官都**引用**另一件器官的内容，风格因此变成一张网而不是一堆抽屉。

3. **材质色低饱和、注意力色高饱和**（v3 的关键分离）：
   - 材质色（纸黄、黄铜、相纸白、砖红、苔藓绿）**一律降饱和**（S ≤ 45%），面积小，形状稳定。
   - 注意力色（主色青绿、信号珊瑚）**高饱和**，面积大或位置显眼，但全页只允许一处主色区。
   → 这样「百花齐放」不会变成「万紫千红」。

### 3.5.3 冲突消解表（两种风格抢同一块地时怎么办）

| 冲突 | 裁决 |
|---|---|
| 赛博 HUD（切角） vs 漫画（直角分格） | 切角只给 `dial` 一个器官，其它器官的容器一律直边 |
| 像素（0 圆角） vs 全站 8/12 圆角 | **像素舱整体 0 圆角**，这是它唯一被允许破坏圆角规则的地方（§1.5） |
| 涂鸦（手绘不等圆角） vs 圆角两档 | 涂鸦层是**叠加层**不是容器，不受容器圆角约束，但不许画到容器外面 |
| 蒸汽朋克黄铜 vs 复古票券冲压纸 | 两者都是「暖」，必须**色相拉开**：黄铜偏橙金（~40°），票纸偏黄绿（~55°），且不能同屏出现 |
| 宫崎骏苔藓绿 vs 像素单色阶 | 苔藓绿只出现在 `plate`（B 级），像素舱里不许出现绿 |
| 校园卡砖红（实物） vs 信号珊瑚 | 砖红 S≈57%、B 低；珊瑚 S 高、B 高。两者**永远不同框**；刷卡器官本身就是半框遮罩态 |

## 4. 排版（决定「高级」还是「土」的最后一公里）

- 字号阶梯只用 5 档（如 11 / 13 / 15 / 18 / 24），不许出现 12.5 / 14.5 / 17 这种中间值。
- 字重只用 **400 / 500 / 700** 三档。
- 对比层级 = **尺寸 + 字重 + 颜色** 三者组合，不能只改字号。
- 全站数字 `tabular-nums`（已落）。
- 4px 基准网格；容器内边距 ≥12px；区块间距 ≥32px。
- 圆角只有两档（`--n-r-sm` 8px 给控件 / `--n-r-md` 12px 给容器），其余全部归零。
- 行高：正文 1.5~1.6；读数/标题 1.15~1.25。

## 5. 「不腻」的自我检验（任何人改完都要过这 5 问）

1. **灰度测试**：截图去色后，层级还分得清吗？分不清 = 你在用颜色掩盖结构问题。
2. **三屏测试**：连续看三个页面，高饱和色出现超过 3 次吗？超过 = 强调失效。
3. **一周测试**：这个元素用户第 7 天还会注意到吗？会 = 太吵；永远不会 = 可以删。
4. **删减测试**：把这一屏任意一个装饰元素删掉，功能受影响吗？不受 = 它必须证明自己值得占位。
5. **单手测试**：拇指能否到达？长按/拖动是否需要第二只手？

**写域铁律**：

- 材质色一律降饱和（S ≤ 45%），高饱和只留给主色与信号色。
