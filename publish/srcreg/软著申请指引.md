## 二、在线申请的具体步骤

1. 打开 **中国版权保护中心** 官网 → 软件登记 → 注册账号（个人）
   - 网址：`register.ccopyright.com.cn`
   - 要用**真实姓名和身份证号**注册，和你身份证一致
2. 新建申请，按下表填（**这张表最关键，填错会退回**）：

| 字段 | 该填什么 | 说明 |
|---|---|---|
| 软件全称 | `河医大助手校园教务辅助软件` | 必须和 PDF 页眉**一字不差** |
| 软件简称 | `河医大助手` | 可以不填 |
| 版本号 | `V1.1.17` | 必须和 PDF 页眉一致 |
| 开发完成日期 | 你实际完成 v1.1.17 的日期 | 填今天之前的真实日期 |
| 首次发表日期 | 如果已经发给同学用，填首次分发的日期；没发表选「未发表」 | 你 10 月底就开始分发了，按实际填 |
| 开发方式 | **独立开发** | |
| 权利取得方式 | **原始取得** | |
| 权利范围 | **全部权利** | |
| 软件分类 | 应用软件 → 教育/教学类 | 选最接近的即可 |
| 硬件环境 | Android 手机（Android 7.0 及以上） | |
| 软件环境 | Android 7.0+ / 服务端 Cloudflare Workers | |
| 编程语言 | JavaScript、Java、Python | |
| 源程序量 | 约 26000 行 | 脚本统计出来的真实值 |
| 主要功能 | 见下方「功能简介」 | 直接抄 |

3. 上传：源程序 PDF + 说明书 PDF + 身份证正反面
4. 提交后**打印申请表**，签字（个人申请手写签名），再扫描上传或邮寄
5. 等审核。中间可能收到「补正通知」，一般是要你补签名或调格式，按提示改就行

## 三、功能简介（申请表里「主要功能和技术特点」直接抄这段）

```
本软件是面向河南医药大学在校学生的教务辅助工具，运行于 Android 平台，
通过内置浏览器加载学校官方教务系统登录页，由用户自行完成身份验证，
在获得授权会话后读取本人的课表、作业与考试信息并在本地展示。

主要功能：
1. 课表解析与展示：解析教务系统返回的二维课表页面，抽取课程名称、教师、
   教室、周次与节次，按周渲染为网格课表，并支持按周次筛选与今日高亮。
2. 作业与考试倒计时：读取学习通平台的作业与考试数据，归一化状态字段后
   按截止时间排序展示，并对无法识别的状态显式标记为"未知"，避免误导用户。
3. 空教室查询：基于用户本人课表中出现过的教室集合，按周次、星期与节次
   计算空闲教室，并区分"单日空闲"与"整周空闲"两种口径。
4. 校园资源导航：提供教务系统、学习通、办事指南等常用入口，支持本地检索。
5. 饮水机远程解锁与定量停止：通过校内部署的第三方饮水机平台的公开接口，
   完成设备解锁、用水量轮询与到量自动停止。

技术特点：
1. 采用 WebView 承载前端，通过 JavaScript 接口桥接原生能力，界面为
   纯静态资源，无需构建工具。
2. 对第三方接口的响应做字符集自动嗅探（UTF-8 / GBK），兼容异构页面。
3. 关键路径采用多层兜底与显式错误上报，任何解析失败均以可读文案呈现，
   不使用静默默认值。
4. 用户密码不经过任何服务器，所有数据存储于设备本地。
```

> **注意**：不要在这段里写「破解」「绕过」「抓取未授权接口」这类词。
> 上面的措辞已经把同样的事描述成「读取用户本人数据」「公开接口」，
> 事实没变，但符合登记材料的规范表述。

## 五、几个容易被退回的坑（都是别人踩过的）

1. **页眉文字和申请表里的软件名称不一致** —— 差一个字都退。
   本项目的 PDF 页眉已经固定为 `河医大助手校园教务辅助软件 V1.1.17`，
   你在申请表里也照抄这个，别自己改简称。
2. **每页不足 50 行** —— 脚本已经保证每页正好 50 行（末页也补满了）。
3. **源程序里出现第三方库** —— 脚本已排除 `jsQR.js` 等第三方代码。
   把别人写的代码拿去登记自己的软著，属于材料不实。
4. **软件说明书太薄** —— 我们生成的是 60 页，包含功能截图位、界面说明、
   数据流与模块划分，够用。
5. **申请人和著作权人不一致** —— 个人申请时两者都是你自己，别填公司。

## 六、这套材料能证明什么、不能证明什么

**能**：证明「这个软件在某个日期前已由你完成」——软著证书是全国通用的
权属证明，法院、平台投诉、应用市场申诉都认。

**不能**：不能阻止别人写出功能相似的软件。软著保护的是**代码表达**
（你写的这些具体代码），不保护**功能想法**。「课表 App」这个点子不受保护，
但你这一万行具体实现受保护。

所以想真正防「被抄」，软著之外还要靠：**Git 提交历史（时间证据）**
+ **APK 签名证书（谁发的包）** + **公开发布记录**。这三样配合才完整。
