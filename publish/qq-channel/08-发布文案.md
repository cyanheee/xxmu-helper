## 〇、为什么一直被屏蔽，这一版改了什么

问题不在文案写得不好，是**正文带了站外链接 + 群号 + 应用分发导流**，这几样在腾讯系是机器审核直接吞，跟内容质量无关。

| 之前正文里的东西 | 为什么被吞 |
|---|---|
| `https://www.xxmuhelper.top`、`pages.dev/v1/apk` | 站外链接 + `.top` / `pages.dev` 这类域名 + apk 下载。腾讯网址安全把「文件下载类链接、来源不明链接」列为风险链接拦截（[网址安全中心标准](https://urlsec.qq.com/standard/s7.html)、[微信外部链接内容管理规范 2.18.3](https://weixin.qq.com/agreement/weixin_external_links_content_management_specification)） |
| 「官网 / 备用直连 / 下载 / 检查更新 / 覆盖安装 / 微信里打开 / 发出来被ban」 | 应用分发导流话术，配长文判成广告推广 |
| 「更新通知群 1097668324」+ 加群字样 | 站外加群导流，平台机器审核重点；社区平台普遍把「正文含站外链接导流」列为违规（[微博社区公约](https://service.account.weibo.com/roles/gongyue)） |
| 「登录教务 / 输学号密码」反复出现 | 密集中容易误判成钓鱼 / 代登录风险 |
| 「抓取部分要跟着更」的「抓取」 | 爬虫 / 破解感 |
| 一次 8 张图 + 长文 + 多个链接，删了又原样重发 | 新号 / 低权重号叠加风控，「重复发布相似内容」按垃圾信息处置 |

另外 [腾讯云天御](https://secsdk.qq.com/) 提供 URL / APK 误报申诉：域名若被标红可先申诉，再谈发布。

**这一版的做法**：正文零链接、零群号、零「下载/官网/加群/被ban」；登录类措辞弱化到「按引导完成一次验证」；「抓取」改「页面调整」；安装包、备用、群号、反馈全放评论区分 4 条发。

## 二、【直接发】正文纯净版

发的时候只复制下面框里的字，别把 ``` 带出去：

```
最开始做它，纯粹是懒得切一堆软件看课表、看作业、接水。

看课表要开教务页面，看作业要开学习通，接杯水还得开一个小程序。一天来回十几遍，有时候就为了看一眼「今天下午有没有课」。后来索性自己写了一个：弄一次，之后打开就是自己的。

它现在能干什么

课表：按引导完成一次校园账号验证，按周排成网格，当前周高亮、今天那列有标记，每门课直接写清教室和起止时间。顶部状态条会把「还没同步 / 本周确实没课 / 周次读不懂 / 读取失败」分开显示，免得对着一张空白表瞎猜。

作业与考试：按紧急程度排好，还剩几小时、什么时候截止一眼看到。状态认不出来的会老实标「未知」，不会替你判成已完成——判错了会让人错过截止，多点开看一次代价小得多。都是只读展示，交作业、考试还是去官方页面。

空教室：按你课表里出现过的教室，算某天哪几节空着，也能找整周都空的自习位。范围只限自己课表里那十几间，别的班安排看不到，结果仅供参考。

接水：学校直饮水走「胖乖生活」，扫一次码记住机器，之后在手机点一下就行。这里说清楚——手机负责解锁，出水还得人在机器出水口按一下物理键，这是机器的设计；「停」可以远程下发，所以做了定量放水，到量自动帮你停，防忘关。

校园 WIKI：官方入口、办事流程、校历、附属医院这些资料归到一处，能搜、能自己补；同学拍的校园实景审过才公开。想加功能、发现 bug、资料写错了，页面底下直接留言就行，管理员回复会公开显示。

隐私，说清楚

账号信息只在学校官方页面填写，App 和服务器都不存；本地会话、课表、作业全留在自己手机上。服务端只管版本号、公告这类轻量状态。没有广告，没有会员，不收成绩。

几句实话

仅安卓。学校系统页面调整时，对应的部分可能要跟着改，我这边会修。所有正式事务（成绩、选课、评教、缴费）一律以学校官方系统为准；这是学生自己写的工具，和学校、超星、胖乖都没有隶属关系。

怎么用

装好打开先翻一遍教程，然后「我的」里按引导完成一次校园账号验证；「学习」页再按引导接一次，作业考试就有了；饮水机用到时再弄。几步都能先跳过，不影响先看课表。

安装包和后续更新放在评论区，需要的同学往下翻。有问题：App 内「我的 → 关于本软件 → 反馈问题」会带一份诊断说明；或者在 WIKI 留言板写一条，我都能看到。

常见几个问题

Q：要校园账号吗？
A：账号信息只在 App 内打开的学校官方页面填写，App 和它的服务器都不存，只留本地会话。

Q：接水是不是点一下就出水？
A：手机只负责解锁，出水还得在机器出水口按一下物理键；「停」能远程，所以做了定量到量自动停。

Q：空教室准吗？
A：只算你课表里出现过的教室，别的班安排看不到，仅供参考。

Q：iOS 有吗？
A：仅安卓，个人开发没有苹果设备和开发者账号。

Q：收费 / 广告？
A：都没有，免费、无广告、无会员。

Q：学校认可吗？
A：学生自建工具，非官方，和学校、超星、胖乖无隶属；正式事务以官方系统为准。

Q：怎么反馈？
A：App 内「我的 → 关于本软件 → 反馈问题」带诊断信息，或 WIKI 留言板直接写，管理员回复公开。也可以直接在这个帖子下问我。
```

## 六、被吞了怎么排查（按顺序）

1. 只发纯文字、把所有链接全删 → 能过，就确认是链接问题，链接逐条挪评论区。
2. 还吞 → 删群号、删「超星 / 胖乖生活」等第三方品牌名再试。
3. 还吞 → 换时段、隔天发；新号别一天连发多条相似内容，别删了又原样重发。
4. 只发带链接的评论被吞 → 主域名可能在 QQ 里被标红，走 [腾讯云天御 / 网址安全中心申诉](https://secsdk.qq.com/) 解标，或改用短时段内新发的备用域名。
5. 图别带二维码、别在图里写网址；正文别贴 `**`、表格、井号标题。
